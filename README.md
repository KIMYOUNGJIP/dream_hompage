# 🌟 2026 연성초 꿈마당(진로의 날) 안내 웹사이트

> **슬로건**: "꿈을 만나고, 꿈을 체험하다"  
> **일시**: 2026년 10월 15일(목) 09:10 ~ 12:20  
> **장소**: 연성초등학교 4·5층 교실 및 복도  
> **대상**: 1~6학년 전교생

초등학생, 교사, 학부모를 위한 **2026 연성초 꿈마당 안내 및 맞춤형 체험 코스 웹 애플리케이션**입니다.  
서버나 데이터베이스 없이 브라우저의 `localStorage`만으로 안전하게 동작하며, GitHub Pages 및 Netlify 등에 정적 웹사이트로 즉시 배포할 수 있습니다.

---

## 🎪 주요 기능 안내

1. **홈 화면 (`/`)**
   - 2026년 10월 15일 기준 실시간 D-Day 카운트다운 타이머
   - 오늘의 행사 개요 및 타임라인 요약
   - 4대 주요 메뉴 퀵 바로가기 (부스 둘러보기, 층별 배치도, 맞춤 시간표, 나의 코스)
   - 전교생 4대 참여 원칙 안내

2. **부스 둘러보기 (`/booths`)**
   - 총 15개 부스 (학생 12개, 외부 2개, 학부모 1개) 카드 그리드 표시
   - 층별(4층/5층), 운영 주체별(학생/학부모/외부) 탭 필터링
   - 부스명, 활동 내용, 학급 실시간 키워드 검색
   - 하트(💖) 버튼으로 나만의 코스 담기/빼기 지원

3. **부스 상세 안내 (`/booths/:id`)**
   - 부스 활동 내용, 단계별 체험 순서
   - 교실 내 상세 위치, 소요 시간, 대상 학년
   - 준비물 및 안전·알레르기 유의사항
   - **인접 부스 2개 자동 추천** (이동 동선 최적화)
   - 배치도 연동 바로가기

4. **층별 인터랙티브 배치도 (`/map`)**
   - **SVG로 직접 구현한 4층·5층 평면도** (동아리실, 이음교실, 일반교실, 복도, 중앙계단)
   - 4층 ↔ 5층 전환 탭
   - 모바일 친화적 돋보기 확대/축소(+/-) 및 초기화 컨트롤
   - 내가 찜한 부스는 노란색 발광 테두리 및 💖 하트로 시각적 하이라이트
   - 교실 및 부스 클릭 시 상세 미리보기 카드 및 바로가기 제공

5. **맞춤 시간표 (`/schedule`)**
   - 1~6학년 선택 및 4~6학년 A조/B조 선택 지원
   - 선택한 학생의 **1일 개인 맞춤형 타임라인 카드** 자동 생성 (20분 단위 행동 지침)
   - 전체 타임테이블 표(20분 단위) 및 4대 참여 원칙 안내

6. **나의 코스 & 인쇄 활동지 (`/my-course`)**
   - 내가 담은 부스 목록 및 체크리스트
   - 체험 완료 체크 기능 및 진행률 달성 바 (예: 4개 중 2개 완료 50% 🎉)
   - **A4 1쪽 맞춤 인쇄 기능 (`@media print`)**:
     - 학생 인적사항(학년, 반, 번호, 이름) 기재란
     - 확인 도장(스탬프) 날인 칸이 포함된 깔끔한 체크리스트 양식

7. **선생님용 운영 대시보드 (`/teacher`)**
   - 교실 TV 및 전자칠판(1920px) 띄우기용 대형 화면 모드 지원
   - 사전 안전교육(09:10~09:30) 4대 핵심 강조사항
   - 안전 관리 및 응급상황 대응 수칙
   - 고학년 5대 부스 운영 역할 분담표 (체크리스트 저장 기능)
   - 행사 필수 준비물 점검표 (체크리스트 저장 기능)
   - 행사 예산 집행 계획표 (계획서 내역 반영)

## 🛠️ 선생님을 위한 행사 데이터 수정 가이드

교사가 코드 전체를 몰라도 `src/data/` 폴더 안의 파일만 메모장이나 코드 편집기로 수정하면 웹사이트의 모든 내용이 즉시 바뀝니다.

| 파일 경로 | 수정 가능한 내용 |
|---|---|
| [`src/data/booths.ts`](src/data/booths.ts) | 15개 부스 정보(부스명, 활동 내용, 위치, 이모지, 준비물, 주의사항, 소요시간, 추천 인접 부스 등) 및 행사 기본 정보(날짜, 시간, 슬로건) |
| [`src/data/schedule.ts`](src/data/schedule.ts) | 1부/2부 시간 운영 계획, 20분 단위 상세 타임테이블, 학년별 맞춤 타임라인 안내 문구 |
| [`src/data/teacherGuide.ts`](src/data/teacherGuide.ts) | 아침 사전교육 강조사항, 안전 수칙, 학생 역할 분담표, 준비물 점검표, 예산 내역 |

> **TIP (부스 내용 바꿀 때)**:  
> 예를 들어 4학년 1반의 활동 내용이나 부스명을 변경하고 싶다면, `src/data/booths.ts`에서 `b4-1-1`을 찾아 `name`이나 `description` 한글 텍스트만 따옴표(`' '`) 안에 수정하시면 됩니다.

## 🚀 배포 방법 (GitHub Pages / Netlify)

### 1. 정적 빌드 파일 생성
```bash
npm run build
```
빌드가 완료되면 프로젝트 루트에 `dist/` 폴더가 생성됩니다.

### 2. GitHub Pages 배포
- `vite.config.ts`에 `base: './'` 상대경로가 적용되어 있으므로 저장소 이름과 무관하게 서브 경로에서도 완벽하게 로드됩니다.
- `dist/` 폴더의 내용을 `gh-pages` 브랜치에 푸시하거나, GitHub Actions를 통해 자동 배포할 수 있습니다.

### 3. Netlify 배포
- Netlify 대시보드에서 `dist` 폴더를 드래그 앤 드롭하기만 하면 10초 만에 전 세계에 무료 배포됩니다.
- 빌드 커맨드: `npm run build`
- 퍼블리시 디렉토리: `dist`

## 🎨 기술 스택
- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS (초등학생 친화 파스텔 톤 테마, `@media print` A4 최적화)
- **Typography**: Pretendard Web Font
- **Icons**: Lucide React & 유니코드 이모지
- **Routing**: `react-router-dom` (HashRouter 기반)
- **Persistence**: Web Storage API (`localStorage`)
